# Introduction to Machine Learning

## What is machine learning?

Machine learning (ML) is a branch of artificial intelligence that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for each task.

### Core idea

Instead of writing detailed rules for every situation, you train a model on examples (data). The model adjusts its internal parameters to minimize errors, then uses what it “learned” to handle new, unseen data. In formal terms, a program “learns” if its performance on a task improves with experience (data).

### How it works (simplified)

1. **Data collection:** Gather historical examples (e.g., photos labeled “cat” or “dog”).

2. **Model training:** An algorithm finds patterns in the data by optimizing a mathematical model.

3. **Evaluation & deployment:** Test on new data; if accurate enough, deploy to make real predictions.

### Main types of machine learning

1. **Supervised learning:** Learns from labeled data (input–output pairs). Common tasks: classification, regression.

2. **Unsupervised learning:** Finds structure in unlabeled data (e.g., clustering, dimensionality reduction).

3. **Reinforcement learning**: Learns by trial-and-error using rewards/penalties (common in games, robotics).

## Short Brief History of Machine Learning

Machine learning grew out of mid‑20th‑century work on artificial intelligence, neural networks, and statistics, with key breakthroughs in the 1950s, a “deep learning” boom from the 2000s onward, and a generative‑AI explosion in the 2020s.

### Early foundations (1940s–1950s)

* **1943:** Warren McCulloch and Walter Pitts publish a mathematical model of a neuron, laying groundwork for neural networks.

* **1950:** Alan Turing proposes the Turing Test and the idea of machines that can learn.

* **1951–1952:** Marvin Minsky and Dean Edmonds build SNARC, an early neural‑network machine; Arthur Samuel creates a checkers program that improves with play.

* **1957:** Frank Rosenblatt invents the perceptron, the first trainable neural network unit.

* **1959:** Arthur Samuel coins the term “machine learning.”

### Algorithms and AI winters (1960s–1990s)

* **1960s–1970s:** Early pattern‑recognition systems, symbolic learning, and the first chatbot (ELIZA) appear; interest fluctuates (“AI winters”) as limits of early methods become clear.

* **1986:** Backpropagation is popularized (Rumelhart, Hinton, Williams), enabling training of multi‑layer neural networks.

* **1997:** IBM’s Deep Blue defeats chess champion Garry Kasparov, showcasing advanced search and learning in games.

### Rise of deep learning (2000s–2010s)

* **2006:** Geoffrey Hinton and others revive deep learning with deep belief nets and better training methods.

* **2012:** AlexNet wins ImageNet, triggering widespread adoption of deep neural networks for vision and beyond.

* **2016:** DeepMind’s AlphaGo beats Lee Sedol at Go, demonstrating reinforcement learning and deep nets in complex strategy.

* **2017:** The Transformer architecture is introduced, becoming the backbone of modern language models.

### Generative AI era (2020s)

* **2022:** ChatGPT launches publicly, bringing large language models and generative AI to mainstream use.

Since then, diffusion models, multimodal systems, and ever‑larger models have rapidly expanded what ML can do in text, images, audio, and code.
